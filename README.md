# Hungry Hippo

Hungry Hippo is a terminal-based food ordering system created for CS 2114 Project 1.

The program collects a customer's name and selected allergens, filters out incompatible menu items, and allows the customer to build an order from the remaining foods. Customers can add or remove items, and the program calculates the final order total.

## Features

- Terminal-based food ordering
- Customer name and input validation
- Allergen-based menu filtering
- Six supported allergen groups:
  - Dairy
  - Gluten
  - Peanuts
  - Tree Nuts
  - Eggs
  - Soy
- Add and remove food items
- Automatic order total calculation
- Invalid input handling

## How to Run

Compile the project, then run `Main.java`.
